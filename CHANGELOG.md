## v0.1.0 — 2026-09-14

Initial experimental developer release:

- Independent Python library, CLI, and optional FastAPI server.
- Offline scene extraction with optional Gemini analysis and generation.
- Versioned Analysis JSON with evidence fields and narration budgets.
- Structure-preserving generation, silent-beat rewriting, and deterministic validation.
- Bounded jobs, SQLite result persistence, and upload cleanup.
- Tests on Python 3.11–3.13, Docker build, examples, schemas, and related-project comparison.
